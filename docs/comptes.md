# Comptes à créer (gratuits, à faire par Celia)

Claude Code ne peut pas créer de comptes à ta place. Voici les 3 comptes, dans l'ordre. Aucun ne demande de carte bancaire.

## 1. GitHub (maintenant : sert au premier test)
1. Va sur https://github.com/signup et crée un compte avec ton mail.
2. Donne ton nom d'utilisateur GitHub à Claude Code.
3. Claude Code te guidera pour créer le dépôt `recettes` et mettre l'appli en ligne.
   L'adresse sera : `https://<ton-nom>.github.io/recettes/`

## 2. Supabase (à l'étape 2 : la base de données partagée)
1. Va sur https://supabase.com, « Start your project », connecte-toi **avec GitHub**.
2. Crée un projet « recettes », région Europe (Paris ou Francfort), offre **Free**.
3. Note le mot de passe de la base dans un endroit sûr. **Ne le colle pas dans le chat.**

## 3. Brevo (à l'étape 2 : envoi du code de connexion par mail)
1. Va sur https://www.brevo.com, crée un compte gratuit.
2. Claude Code te dira quoi copier dans Supabase (réglages « SMTP »). Les clés vont directement dans Supabase, jamais dans le code ni dans le chat.

## Premier test (étape 1)
- **Android (Celia)** : ouvre l'adresse dans Chrome → menu ⋮ → « Installer l'application ». Puis dans Insta : une vidéo → Partager → **Recettes** → tape 2-3 mots → Enregistrer.
- Note ce que tu vois. Si « Recettes » n'apparaît pas dans Partager, dis-le à Claude Code.
